# Игра в жизнь

Консольная реализация клеточного автомата **Conway's Game of Life** на языке C.

## О проекте

«Игра в жизнь» — клеточный автомат, в котором состояние каждой клетки определяется состояниями её восьми соседей. Игра является детерминированной: каждое следующее поколение полностью зависит от предыдущего.

Для каждой клетки применяются следующие правила:

- живая клетка с двумя или тремя живыми соседями выживает;
- мёртвая клетка с тремя живыми соседями становится живой;
- живая клетка с менее чем двумя соседями погибает;
- живая клетка с более чем тремя соседями погибает;
- остальные мёртвые клетки остаются мёртвыми.

Состояния всех клеток обновляются одновременно при переходе к следующему поколению.

## Реализация

Проект реализован на языке **C** в структурном стиле и работает непосредственно в терминале.

Основные возможности:

- визуализация игрового поля с использованием ASCII-графики;
- размер поля — **80 × 25 клеток**;
- замкнутая топология поля: клетки на противоположных границах считаются соседними;
- загрузка начального состояния через `stdin`;
- поддержка нескольких заранее подготовленных начальных конфигураций;
- интерактивное изменение скорости симуляции;
- возможность завершения работы программы без перезапуска;
- использование библиотеки `ncurses` для работы с терминалом и интерактивным управлением.

## Управление

- `A` — увеличить скорость симуляции;
- `Z` — уменьшить скорость симуляции;
- `Space` — завершить программу.

## Структура проекта

Основной файл программы:

```text
src/game_of_life.c
```

Начальные конфигурации могут передаваться программе через перенаправление стандартного ввода.

Пример:

```bash
./game_of_life < patterns/pattern.txt
```

## Требования к качеству кода

При разработке учитывались следующие требования:

- структурный стиль программирования;
- отсутствие громоздких функций;
- контроль утечек памяти;
- проверка кода с помощью `cppcheck`;
- форматирование кода с помощью `clang-format`;
- отсутствие использования `system()` и аналогичных системных вызовов.
